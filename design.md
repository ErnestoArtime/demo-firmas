# Demo Firmas — sistema visual

**Dirección:** Workbench de documentos. La interfaz es una mesa de producción, no una página promocional: el usuario ve, selecciona y genera documentos sin distraerse de la secuencia de trabajo.

- **Tono:** preciso, sereno y editorial.
- **Paleta:** papel cálido, tinta azul profunda y coral para las acciones de avance.
- **Tipografía:** Fraunces para jerarquía y DM Sans para controles y lectura de interfaz.
- **Estructura:** cabecera tipo cuaderno, una columna de etapas con paneles de papel y resultados diferenciados. La misma base de tokens queda disponible para las rutas de borradores y firma.
- **Movimiento:** entrada discreta de etapas y desplazamientos de 1 px en interacciones; se respeta `prefers-reduced-motion`.

No se altera el flujo, las llamadas API ni las validaciones existentes.
